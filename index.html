Firebase 项目连接

每位注册用户拥有独立资料。Firebase Web 配置不是密码，请勿把服务账号私钥放在网页里。

设置步骤
  1. 到 Firebase Console 建立项目，并新增 Web App。
  2. Authentication → Sign-in method → 启用 Google。
  3. Authentication → Settings → Authorized domains 加入 GitHub Pages 域名。
  4. Firestore Database → 建立数据库，并设置下方安全规则。
  5. Storage → 启用储存空间，并设置下方规则，供笔记图片使用。
  6. 把 Web App 配置填入上方，保存后即可登录。
